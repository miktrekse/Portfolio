# Portfolio (Static)

This is a minimal static portfolio site you can deploy to Vercel.

How to use

1. Replace placeholders in `index.html` (your name, about, skills, project links and images).
2. Commit this folder to a GitHub repository.
3. Deploy to Vercel by connecting the GitHub repo at https://vercel.com/new or using the Vercel CLI:

```bash
npm i -g vercel
vercel --prod
```

Notes

- Each project card already includes a GitHub link placeholder and a demo link placeholder — replace them with real URLs.
- Images currently use `https://via.placeholder.com`. Replace with your screenshots in an `assets/` folder if you prefer.
